# Spliit

1인 가구를 위한 동네 소분·공동구매 앱 프로토타입입니다. 대용량 식재료와 생필품, 배달 음식을 근처 이웃과 안전하게 나눠 살 수 있도록 설계했습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.

GitHub Pages로 배포하려면 저장소 Settings > Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 지정하세요.

## 화면 구성

- 홈: 근처 소분 모임 목록, 카테고리 필터, 마감 임박 배너
- 모임 상세: 품목·금액·픽업 장소·참여 현황, 에스크로 결제 안내
- 모임 개설: 모집 성별(여성만·남성만·상관없음), 인원 선택, 1인당 예상 금액 자동 계산
- 동네할인: 근처 마트·편의점 할인 정보, 가게 할인 등록
- 채팅: 참여자 간 대화
- 파기 정책: 에스크로 흐름, 취소 시점별 환불·신뢰 점수 기준, 분쟁 신고
- 내 정보: 신뢰 점수, 거래 내역, 절약 금액

## 상태

UI 프로토타입이며 결제, 위치 인증, 채팅 서버는 연결되어 있지 않습니다.
